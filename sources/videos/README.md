**התיקון הנדרש:** לגלול **עד שהתמונה מפסיקה להשתנות** (זיהוי תחתית) במקום
מספר קבוע, ולהרחיב את פס ה-`OCR`. אחר כך לסרוק מחדש מההתחלה.

## איך ממשיכים

1. Phone Link פתוח עם שיקוף, האפליקציה פתוחה על נקודה כלשהי
2. לתקן את `scan-videos.ps1` לגלילה עד תחתית
3. `powershell -NoProfile -File scripts/phone-capture/scan-videos.ps1 -Steps 100 -Out out.tsv`
   (מקטעים של עד 100, כי כל קריאת `Bash` מוגבלת ל-10 דקות וכל נקודה לוקחת ~5 שניות)
4. ⚠️ **אסור למשתמש לגעת במחשב בזמן הריצה** - חטיפת פוקוס גורמת ללחיצות עיוורות

## מלכודות שהתגלו בסריקה הזאת

- **גלילה עם הגלגל מעל התרשים המרכזי מזמת את התמונה** במקום לגלול. חובה לגלול ב-`x=200`
- **לחיצה בראש הדף עלולה לנחות על נגן הווידאו** ולהפעיל אותו
- `mouse_event` ב-PowerShell לא מקבל דלתא שלילית - להעביר `4294966936` עבור `-360`
- **עצירה על חזרה בודדת בכותרת שגויה** - ה-`OCR` מייצר לפעמים אותו טקסט לשתי נקודות שונות. לעצור רק אחרי 3 חזרות רצופות
- `nohup ... &` **לא שורד** את סיום קריאת ה-`Bash` - להריץ במקטעים בחזית
